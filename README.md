# Middle Trent DTM

Interactive terrain models accompanying the Middle Trent place-name project.

[Open the models](https://ziyuewwang.github.io/Middle-Trent-DTM/)

14 terrain datasets serve 13 reading locations; Sawley and Shardlow share a selectable viewer. Each model supports terrain rotation, analytical profiles, vertical scales from 1× to 10× and contextual map layers. The default is wireframe at 5× vertical exaggeration.

Model URLs use `viewer.html?group=1&site=long-eaton`, with the appropriate group and site selected from the index. These standalone pages can be embedded in WordPress using an iframe.

See [ATTRIBUTIONS.md](ATTRIBUTIONS.md) for data and software credits. Raw elevation rasters and unpublished research drafts are retained separately.
